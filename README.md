# Guitar Teacher

An Android application made to make your guitar journey easier. Currently in active development and supports:

- Acoustic Guitar Standard Tuning
- Standalone metronome with tempo/meter controls, optional count-in and background media controls

Direct download: [Releases](https://github.com/mehtamohit013/guitar-teacher/releases)

## Install with Obtainium

1. Install [Obtainium](https://github.com/ImranR98/Obtainium/releases/latest).
2. In Obtainium, select **Add App** and enter `https://github.com/mehtamohit013/guitar-teacher`.
3. Select the APK matching your device below, then install and approve Android's prompts.

Obtainium can check for future updates.

If Android blocks installing Obtainium or this APK because the developer is unverified, see [Google's official advanced-flow instructions](https://support.google.com/android/answer/17588095?hl=en). The one-time setup includes a 24-hour security delay; requirements vary by device and region.

## Requirements

Requires Android 9 or newer on ARM64 or x86-64 Android. 32-bit ARM devices are not supported.

| APK suffix | Devices |
| --- | --- |
| `arm64-v8a.apk` | ARM64 Android phones and tablets |
| `x86_64.apk` | x86-64 Android devices and emulators |

Permissions:

- Microphone: tuner only.
- Foreground media playback: metronome.
